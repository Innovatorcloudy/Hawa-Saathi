# Hawa Saathi (हवा साथी) 🌿
### *AI-Powered Winter Smog & Urban Clean Air Companion for Families and Communities*

Hawa Saathi is a purpose-built GenAI web application engineered to protect households and urban communities navigating severe winter smog episodes, temperature inversion layers, and hazardous air pollution (AQI 400–500+).

---

## 🌟 Key Capabilities & GenAI Tools

1. **Hyperlocal Smog Radar & AQI Forecaster**:
   - Live India AQI & WHO 24h particulate multiples (e.g. 26× WHO safe limit).
   - Real-time breakdown of **PM2.5, PM10, NO₂, SO₂, CO, and Ozone**.
   - **Winter Inversion Layer Physics**: Displays thermal inversion severity and tracks the diurnal smog curve (morning ground smoke compression vs afternoon solar ventilation window).
   - Station selector covering key pollution corridors: Delhi (Anand Vihar, R.K. Puram), Noida Sector 62, Lahore, Lucknow, Patna.

2. **Personalized AI Routine Shield**:
   - Formulates lowest-exposure hour-by-hour schedules based on household vulnerability (infants, asthmatics, elderly, outdoor commuters).
   - Identifies high-risk traditional routines and offers protective low-emission alternatives with quantifiable risk reductions.
   - Prescribes appropriate mask grades (tight-fitting N95/FFP2 with nose wire vs cloth mask limitations).

3. **Indoor Air Quality (IAQ) Studio & DIY Purifier Builder**:
   - **Corsi-Rosenthal Box Purifier Calculator**: Computes required Clean Air Delivery Rate (CADR in CFM) based on room square footage and ceiling height.
   - Delivers 4.5 Air Changes/Hour (ACH) for **₹2,450 (~$30)**, saving over **80%** compared to commercial ₹15,000+ purifiers with equivalent PM2.5 filtration.
   - **Multimodal AI Vision Inspector**: Diagnostic tool to analyze filter saturation, motor heat safety, and optimal room placement.
   - **5 Verified IAQ Bio-Hacks**: Micro-particulate damp mopping protocols, cooking exhaust guidelines, door draft snakes, and non-toxic prayer/mosquito repellent alternatives.

4. **Direct Impact & Emission Savings Engine**:
   - Quantifies direct emissions prevented: **Grams of PM2.5 avoided per day**, **kg of CO₂ saved**, and **liters of clean breath air gained**.
   - Celebrates sustainable household milestones (clean heating over biomass, carpooling over solo vehicles, damp mopping over dry brooms) with confetti!

5. **Community Smog Shield**:
   - Neighborhood action board to report and verify illegal garbage burning, road dust violations, and chronic vehicle idling.
   - Synchronization of neighborhood carpool pods and school commute clusters during GRAP emergency stages.

6. **Interactive Multilingual AI Assistant**:
   - Multilingual support: **English, हिन्दी (Hindi), and Hinglish**.
   - Powered by **Google Gemini 2.5 Flash** with native function calling and fallback to an offline intelligent deterministic engine.
   - Text-to-Speech (TTS) integration for accessible audio playback for children and seniors.

## 🚀 Quick Start

### 1. Prerequisites
- **Node.js** v18+ (tested on Node v26)
- **npm** v9+

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Build for Production
```bash
npm run build
npm run preview
```

### 5. Gemini API Configuration (Optional)
The application works immediately out-of-the-box using the built-in Intelligent Engine. To connect live Google Gemini API models:
1. Click the **"AI Core"** button in the header.
2. Enter your Google Gemini API Key (`AIzaSy...`).
3. Click **"Save & Apply"**.

## 🔬 Scientific & Regulatory Reference Standards
- **CPCB**: Central Pollution Control Board Air Quality Index categories and GRAP (Graded Response Action Plan) Stages I through IV.
- **WHO**: 2021 Global Air Quality Guidelines (PM2.5 annual: 5 µg/m³, 24-hour: 15 µg/m³).
- **Corsi-Rosenthal Foundation & UC Davis**: Low-cost DIY particulate air cleaning standards.
- **Lancet Planetary Health**: Indoor particulate pollution reduction protocols.
